# 录制与恢复

接手先读唯一清单、交接、实际进程及浏览器video状态；状态文件不能证明实时运行。浏览器优先复用当前获准且已安装的浏览器插件，按实时工具文档使用其正常接口，不猜窗口标题/ID，不通过命令行/隐藏接口操纵网页。浏览器源画面必须实际前台可见。

## 真实控件命中与前台恢复

播放器按钮可定位或点击返回成功，不保证可见控制条已展开。先绑定本轮实际课程标签，通过该获准接口有文档支持的前台激活操作显示正确标签，再观察前台和当前几何；不复用仍指旧标签的闭包。CDP句柄及Page.bringToFront只是在接口文档明确支持时的例子，不是必需依赖；无CDP时使用该插件已文档支持的正常标签激活、鼠标及只读观察方式，不因此阻塞或另开隐藏接口。暂停用本轮已观察的暂停按钮语义按键并核paused；按钮字形可能变化，不能猜名称。

倍速菜单有显隐动画时，在同一执行cell先正常mouseMoved进入当前可见视频区域唤醒控件，等待控制条显现；只读取得当前速率按钮真实矩形，正常移动到按钮，核可见性与实际命中后才正常点击展开菜单。随后等布局稳定，只读取得真实2x项矩形，正常mouseMoved后再只读核:hover末端元素文本、elementFromPoint命中data-rate=2及父菜单opacity=1，然后正常mousePressed/Released。上述mouseMoved/Pressed/Released和DOM命中字段是已文档支持接口中的实测例子；其他获准插件使用其文档支持的等价正常鼠标与可见命中观察，不要求CDP。事后同时核可见2x按钮与video.playbackRate=2。本次实践曾等待约350毫秒控制条动画；这是示例，不是永久常量，隐藏/动画未结束时回到真实观察，不能沿用旧坐标或写播放器内部属性。

全屏点击不生效时先核前台目标，再正常展开控制条、等动画后操作实际全屏按钮，读取退出全屏图标class和video矩形。播放器CSS页面全屏可能仍有document.fullscreenElement=false；结合模式图标、几何和保存样片完整构图判断，不凭单一属性认定成功或失败。暂停后显示控制条，读取当前进度条矩形，在真实起点附近正常鼠标操作，事后核currentTime=0、paused=true和实际倍速。某次x+微小偏移只是示例方法，绝对坐标不跨窗口复用。

若当前接口报告另一扩展UI面板打开而阻止操作，记录阻塞并等待用户关闭，再按接口规则重新观察；不自动关闭未知面板、不在同轮换入口绕过，也不反复调用已经安全拒绝的原生URL检查。用户后来明确允许恢复并不取消实时工具安全约束。其他获准播放器或混音器观察按其接口边界独立判断，不能反向授权浏览器绕过。

每轮核对当前完整客户端/播放器/课件区域；所有裁剪数字来自本轮几何与保存样片，不携带项目固定坐标或句柄。录制不跨目标turn；窗口移位、遮挡或尺寸变化按失败保留，重新校准后从0单次连续录制。不要拼接失败轮次。课程与回放声音的无麦克风、无外放及人听限制仍按下节实际路由核验，不能用按钮状态代替声音证据。

## 参数和启动

`scripts/record_lesson.py` 接受一个JSON文件：archive_root（用户授权归档根绝对路径）、output（新原始录像绝对路径）、arguments（以已核验FFmpeg可执行文件绝对路径起首的完整命令数组，不含最终output）、microphone_capture（必填，必须是JSON布尔值false；缺失、字符串false或其他值会拒绝启动）。配置不含凭据。单节max时长按源长/倍速+余量，不能替代网站自然结束；只含已经隔离验证的课程音频输入，microphone_capture=false不是实际设备隔离证据。Windows后台隐藏启动，录制时不运行重任务。

声音证据分开记录课程播放目标、唯一录制输入、物理输出、虚拟设备侦听、其他应用会话、保存文件回放目标与实际观察时间。用户要求无外放时，确认物理扬声器静音、虚拟设备侦听关闭、课程和回放都流向已核实的虚拟输出；不为听检擅自恢复外放。设备或默认输出改变、出现新应用声音时重新核对；不能只用microphone_capture=false或音轨存在证明声音隔离。实际无法听音时记录human_listening=false，设备路由检查与声音质量验收分开。

在实际工具中观察倍速/播放/全屏控件，读最新矩形等动画位置稳定后点击；只读video时间、paused、ended、rate、ready及viewport，不能写站点内部播放器状态。复查真实归零。几何校准先短录完整窗口，查看原图及裁剪后的同一课件，课件标题/正文/字幕/水印全保留。跨轮次视口可能改变，故录制必须在本轮自然结束/停录后再交接。

脚本输出同名.录制状态.json、.录制日志.txt、.停止录制；新输出及伴随路径都拒绝覆盖。自然结束后写停止标记，正常发送q；30秒无响应仅结束它启动的子进程，记录failed/stop_timeout并保留文件，不标完成。异常退出仍核查真实进程；只处理明确属于本次的PID，不按进程名批量结束其他应用。

## 恢复判定

| 证据 | 行动 |
|---|---|
| 网页前进但媒体frame/time与文件增长停滞 | 交叉检查真实所属子进程、日志和文件大小/mtime，排除初始化与暂时日志迟滞；保存疑似停滞证据，暂停并正常q封口，exit0也不能据此称课程完整 |
| 源时间不推进或缓冲/错误提示 | 保存证据，按正常网站操作恢复；确认严重源缺失后从0补录 |
| 视口/裁剪变化或无关界面入画 | 暂停并正常保存失败录像，重新短录校准，从0补录；后半段修正不能使前段完整 |
| 健康采集中播放器归零暂停 | 先核对真实frame增长，可在同一采集中重新从0连续播放；记录新的有效起点，前段全部排除，不能套用固定秒数 |
| q超时 | 记录终止方式与失败，确认本次子进程退出；保留RAW，以可播放性和内容复核判断是否能恢复 |
| 正式尾段异常、原始完整 | 从原始另存重编码版，复验时轴和EOF，先不重录来源 |
| 锁屏/休眠/桌面不可操作 | 停止依赖桌面的采集，等待用户恢复，不绕过锁屏或静默弱化安全 |
| 网站/工具安全拒绝 | 不换浏览器、网络请求或别的入口绕过，记录待补并继续独立范围 |

正常q退出0仅说明进程完成封口，不能覆盖此前采集停滞、源缺失或不完整；失败录像保留且不能记课程完成。完整失败与未知根因的分层记录见[最佳实践](best-practices.md)。

输入队列/缓冲、容器、码率和增益必须实测。MKV原始录像方便留诊断，但不会自动修复采集停滞，正式MP4需另存并验收。失败根因未证实保留未知，补录成功不证明根因永久解决。

## 已验证的新恢复约束

系统合成器显示浏览器100、非静音，仍不能证明网页实际有声；网页音量可能为零而video.muted仍为false。必须核对页面可见音量图标，再对保存样片的实际课程语音做内容检查，不依赖单一属性。若页面只读接口没有返回volume，不将缺失值当作100或0。

当前用户明确禁止拼接录制：每节从0到自然结束单次连续录制，失败整节重录。短段仅作声音、几何或冻结原因诊断，不拼接成正式课程。曾尝试的约5分钟分段方案已取消；首段检查通过不能用于宣称整节完整。接手必须读取用户当前连续录制约束，不能沿用过期分段计划。

新出现的应用音频会话可能混入共用虚拟输出；采集前重新检查，并按用户只录课程的授权隔离非课程提示音。关闭本轮回放并核实进程结束后才开始采集。所有更改记录实际观察时间，历史物理静音/侦听状态不能冒充本轮已重验。

播放器控制条有显隐动画时，语义点击返回成功也可能点在旧位置，不能据此认定倍速/音量已改变。本地实测中，按钮元素仍可被定位但当时菜单未真实展开；先通过正常播放器操作显示控制条，等布局稳定，查看可见按钮与菜单后正常点击，再读取实际playbackRate或核对可见音量图标。按钮或菜单点击后状态未变，回到实时观察定位，不写内部播放器属性、不强行点击隐藏菜单。不得把某次固定坐标迁移到另一个窗口。

底部字幕诊断结果摘要目前只列freeze_start；遇到命中时必须读取对应完整日志中的freeze_end和freeze_duration，确定范围。片头等待命中不等于播放中冻结；只有完整日志与同版本画面/语音支持，才判断是否整节重录。

## 采集持续停滞时的本机备用方式

只有在恢复正确前台、控件和当前几何后，仍有实际证据表明原窗口采集持续不可行，保存失败原件并正常收口、核实本次进程退出后，才将DDA等已安装获准采集能力作为备用测试。原窗口当前样片仍正常时继续核验原路线，不能因历史失败或控件点击失败就跳到DDA。只改变采集方式，不绕过站点播放保护、不静默关闭硬件加速或安装软件。GDI窗口短录可能黑屏，必须查看实际文件；不把产生文件视为成功。

本机曾通过DDA（桌面复制，采集一个显示器上实际可见的指定矩形）短测及一节完整录制。先3至5秒原生几何测试，核对显示器output_idx和真实桌面像素坐标；再用ddagrab=output_idx=<index>:framerate=<fps>:draw_mouse=0:video_size=<w>x<h>:offset_x=<x>:offset_y=<y>限定完整课件，视频过滤hwdownload,format=bgra,pad=ceil(iw/2)*2:ceil(ih/2)*2,fps=<fps>。数值取当前实测，不沿用某节固定区域；编码器是否支持该输入须在本机先确认。保持独立课程音频输入。

限定矩形保留标题、正文、字幕和水印，不能收进通知或无关内容。DDA依赖前台显示，窗口移动、遮挡、锁屏和布局改变会影响录像；它不具备窗口采集的遮挡隔离。先保存30至60秒含课程讲话的样片，实际播放检查、核对语音内容和音画，记录人工听检限制，才从0开始一节单次连续录制。不得同时运行另一路媒体或移动窗口；发生遮挡按失败整节重录。自然结束后确认q停录及本次进程退出。
