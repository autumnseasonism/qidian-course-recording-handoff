# 最佳实践与错误恢复

用于复用真实执行经验、排查播放器/采集/衍生阶段失败。先核当前授权、接口限制、清单和实际进程；本页不是新授权，也不依赖某个项目路径、账号、tab、PID或坐标。

## 先分清三层证据

| 层次 | 能证明什么 | 不能代替什么 |
|---|---|---|
| 实际进程/阶段返回值 | 本次命令是否结束、退出数值、所属进程是否释放 | 视频完整、文字准确或人工验收 |
| 文件身份/结构/完整解码 | 对应同一版本、可解码、页数/顺序/时间覆盖一致 | 页面无遗漏、口述无缺字、音画同步 |
| 实际画面/回放/声音内容/人工听检 | 对应哈希版本和已观察范围内的内容证据 | 未观察区间或其他长时课节的可靠性 |

q正常封口exit0不能使此前停止写入的录像变完整；ASR全覆盖不等于逐字准确；六张可读预览不能把PPT渲染非零改成成功。每层分别记录范围、版本、结果和未知项，人工听音不能执行时human_listening=false。主Agent复核后才更新唯一清单，失败不计完成。

## 每节开始、监看和收口

1. 按[录制与恢复](recording.md)确认真实前台、实际倍速、零点、声音隔离和本轮几何。用户要求连续录制时从0到自然结束单次采集；不跨录制turn、不拼接，短段只供诊断。
2. 保存30–60秒包含讲话的样片，查看完整课件/字幕/水印，实际回放并核声音内容及同步限制，再判断本轮可开始。短样片只验证当时条件，不能外推47分钟或每一后续课节可靠。
3. 同时观察源时间、实际FFmpeg frame/media time、文件大小/mtime及所属子进程。静态课件不是停帧事实；初始化未输出、日志刷新迟滞或容器缓冲不直接定失败。多个实际观察持续停滞而源推进时记录疑似采集停止，不补造根因。本版脚本未增加自动看护，监看须由执行者按实际工具完成。
4. 停滞或几何异常先暂停来源并留诊断，再通过正常q停止，等实际退出；30秒兜底仅处理所属子进程。不能盲杀其他PID、重复启动并行采集或将人工停止覆盖成其他失败原因。退出后核本次PID及其子进程终态，原始文件、日志与失败状态全部保留。
5. 严重采集缺失整节从0重录；不得把未采到部分由其他轮次拼齐。重录前核资源空闲、恢复前台/控件、重新几何与样片；仅原窗口仍持续不可行有实际证据且所属进程已正常释放后，才测试已有且获准的DDA等备用采集能力，不安装、不改变安全/硬件加速/外放设置。
6. 自然结束也须同版本整文件诊断、固定时码首中尾画面、实际回放范围与声音内容、异常段复核及精确边界证据；未知的保持needs_review。详见[逐节验收](verification.md)。

## FFplay输出读取与回放时间证据

FFplay启动时即确定stdout/stderr处理方式；使用管道时立即持续读取两路输出直到进程关闭，降低日志量不能代替持续读取。按实际工具支持可选择受控inherit；确无日志需求时可选择受控ignore，并记录所选方式和错误证据缺口。无人读取的输出积压可能干扰回放，这只是需要日志和可比条件验证的推断；发现疑似卡住时先查本次播放器所属进程、输出读取状态及日志，不直接判原媒体卡顿。

分别记录调用与实际退出时间、OS实际退出值及调用到退出的墙钟间隔，并另记播放期间实际画面观察和截图完成时间。调用到截图完成的墙钟间隔包含播放器启动及截图接口延迟，不能当精确媒体时码或连续观察时长；未实际保存媒体时码时标未知。关闭后才请求截图不算已查看；退出0、无错误日志或空PID不能单独证明完整播放、结束页已看、声音质量或精确同步。结束后用CIM核本次PID、子进程及与本次输入／播放器命令精确对应的相关进程为空，确认回放和其他重任务均已释放才开录；进程检查只证明资源释放，不替代内容验收，不按通用程序名清理其他任务。无法人工听检时human_listening=false，精确同步未核保持unknown。

## UI恢复与安全阻塞

可见控件命中与实际速率比点击调用成功更有用。优先当前获准已安装浏览器插件，按实时文档正常操作。详细顺序只在[录制与恢复](recording.md)维护：先正常移入视频唤醒控件、核速率按钮真实命中再展菜单，随后核2x真实hover/elementFromPoint命中、菜单可见、正常点击及actual rate。用插件文档支持的方式激活正确tab；CDP/Page.bringToFront仅文档支持时可用的例子，无CDP不阻塞。CSS全屏结合图标/几何/样片判断。任何固定等待和坐标都属于示例，下一次重新观察。

接口提示另一extension UI open时等待用户关闭，禁止同轮换入口绕过；原生URL安全拒绝不反复调用或绕行。保留当前阻塞及解除条件，不把初始失败写成“功能永远不可用”，也不把用户允许继续恢复当成取消工具限制。录制优先，其他Agent只做独立小文本；不控制同一浏览器、不同时运行重媒体。

## 衍生文件与错误恢复

逐字稿保存全部原识别、词级时码、核心/重叠计划、覆盖表与原疑点；按实际任务单区块行号建入口，保留原句/原类型/原窗/原序，不猜改。首尾无文本和相邻同文须回原音画，不能自动判静音/漏录或删除真实重复。

页面先查看候选原分辨率，按真实展示状态选择；原标题、字幕与水印不裁去，不修补遮挡文字。逐页检查PNG/索引/CSV/PDF/PPT数量、顺序、嵌图身份、比例、crop、页脚及备注时码，并实际查看每张渲染预览。精确切换边界、动画增量和遮挡可读性各记限制；参考[衍生资料](derivatives.md)，其初版样例说明属于历史能力记录，不能替代本次实测。

导出、渲染和父调度器分别保存PID、实际退出值、stdout/stderr。PPT渲染非零但预览已生成时保留两项事实，预览可供检查，流程仍失败；底层Node退出或根因没捕获就写未知，不能以JavaScript exit事件0代OS退出，不能清零exitCode、强制成功或盲重试。若需诊断，先等录制空闲且获得该范围授权，再另存诊断副本，不改官方包或旧成果。

## 已观察案例与未解决问题

以下为截至2026-10-03的脱敏经验摘要，不是本次机器的实时状态，也不携带项目运行产物。

- 播放器初始多次点击未生效，后来先正常移入视频唤醒控件并核速率按钮实际命中，再同cell展菜单、真实hover/命中2x并正常点击，实际按钮2x与playbackRate2确认。全屏需激活正确tab，模式图标和真实矩形确认；CSS页面模式可无原生fullscreenElement。此证据支持恢复步骤，不证明今后无需重新观察。
- 一次窗口采集约48秒后frame/time及文件增长持续停滞；另一次连续补录在frame8390、媒体time335.96秒、文件14336KiB处停滞约40秒而源继续推进，源随后暂停在740.209381秒且rate2。正常q最终exit0、文件14986912字节，所属PID及子进程已释放，但内容不完整，不能入完成清单。窗口最小化发生精确时点与因果、第二次停滞根因均未知；与URL安全拒绝没有因果证据。
- 已安装DDA（桌面复制，采集显示器上实际可见矩形）曾有短样片及一节完整课证据。它只在原窗口恢复前台/控件/几何后仍持续不可行有实际证据、失败采集正常收口且所属进程释放后作为备用，不是历史失败后的默认下一路线。启用前重新核显示器和原生几何，30–60秒样片核对后才从0连续；备用计划未执行不能写成功，原窗口样片仍正常时不跳过原路线核验。DDA对遮挡/移动/锁屏敏感，不具备窗口遮挡隔离；不从短90/45秒样片推断47分钟可靠。
- 页面版已有六组真实PDF/图片PPT与对应预览检查，页数、源图绑定和可见构图已有局部证据；PPT官方非零渲染仍待处理，字幕遮挡、短页面与精确页界仍有待核。此记录不证明全部课程页面质量或人听通过。
