# 逐字稿边界只读审计

`--root` 必须是实际普通目录的绝对路径；先用 `lstat` 检查提交的根自身和词法祖先，再解析路径。根或祖先是 junction/符号链接时拒绝；文件路径检查同样拒绝断链，不能通过解析链接隐藏来源。

`scripts/audit_boundaries.py` 为技能自带 `transcribe_lesson.py` 的原始输出提供可追溯只读审计。Python 3.9+，仅标准库；不读取视频或声音，不重新识别，不自动添加或去重，不修改正式逐字稿。

```text
python scripts/audit_boundaries.py --root <授权归档根目录> --source-dir <原始整节转写目录> --output evidence/boundary-audit-01.json
```

来源目录必须包含 `处理状态.json`、`整节时间码逐字稿.json`、对应 Markdown、疑点 JSON、覆盖 CSV，以及状态指向的 `001-原始识别.json` 等原始识别。输入须为完成但待校对的原始识别，四份输出的状态哈希须匹配；另存修复后的稿件不是本工具的原始基线。状态、正式结果与每个原始窗口的签名、核心/输入时间范围必须一致且核心窗口连续。按原脚本“词起止时间中点落入核心窗口”规则重建正式稿行，要求与正式 JSON 完全一致，否则拒绝出报告，保留原件先查明来源。

候选仅覆盖：相邻窗口在同一边界处出现相同整句、相同原词，两个词的时间范围重叠且都跨边界，两边中点各自落在自己的核心范围外，同时正式稿没有该重叠原词。报告给出零起始 `[窗口, 句, 词]` 位置、原始文件名及 SHA256、完整词时间与文字；多对匹配标记 `ambiguous_do_not_restore`，单对也只是 `needs_source_review`。

原稿中的真实重复保留，任何候选都不是“原音频确实说过”的证明。工具不覆盖同句文字不同、识别错词、全部时间漂移、连续漏识别、音画同步等情况。应结合原始上下文和授权本地声音回放复核后，明确选择来源词及哈希、位置，才另存修复；此版本未提供自动修复入口。已有报告拒绝覆盖，路径须在授权根目录内且无链接/Windows 重解析点，输出父目录须存在。报告 `human_listening=false`，不得把本审计等同人工听检或整节验收。
